Compare. Decide. Gate.

    Compare locally

    Parse digital PDF, DOCX, HTML, Markdown, or text. Align clauses through moves, splits, and merges.

  2. 2

    Review the evidence

    Confirm, reject, modify, or waive findings in the packaged loopback-only Reviewer.

  3. 3

    Protect the pull request

Five-minute path

Compare two local policy files.

Install the published package from PyPI and generate a self-contained HTML report. Your policy text stays on the machine.

Read the full documentation →
terminal
$ python -m pip install governdiff

$ governdiff diff \
  old-policy.md \
  new-policy.md \
  --format html --output report.html

✓ 1 change · 2 findings · evidence retained

Deliberate boundaries

Evidence for a person—not a legal conclusion.

  • Breaking is a deterministic review cue, not legal advice or a compliance determination.
  • Digital-text inputs only; image-only PDFs are diagnosed and OCR is not performed.
  • No accounts, hosted document processing, telemetry, remote AI, or public Reviewer service.
  • All examples, reports, screenshots, and performance fixtures on this site are synthetic.
