# GovernDiff roadmap

The detailed implementation ledger lives in `docs/IMPLEMENTATION_ROADMAP.md`.
This file is the concise public roadmap.

## Release candidate — local preparation complete

- Deterministic PDF, DOCX, HTML, Markdown, and text comparison.
- Evidence-backed breaking checks, stable fingerprints, waivers, and report
  schemas.
- Local Reviewer, clean-install packaged assets, accessibility/performance gates,
  public examples, contributor documentation, and licence audit.

Publication remains a separately authorized operation: approve local history,
create a remote, run hosted CI, choose the final version, tag, upload to PyPI,
create a GitHub Release, and deploy the public Reviewer demo.

The local completion record and exact candidate hashes are in
`docs/PHASE_8_PRE_RELEASE_COMPLETION.zh-CN.md`.

## Demand validation

- Interview 8–12 policy, compliance, governance, and developer-tool users.
- Run the Action in three real repositories.
- Measure review time, cost, and missed-change baselines.
- Re-audit competitors and test the Policy CI positioning.
- Record a dated go/no-go decision before expanding scope.

## Deferred until evidence supports it

- OCR for image-only PDFs.
- Optional AI review assistance with an explicit privacy boundary.
- Remote collaboration, accounts, telemetry, or hosted document processing.
- Additional report-contract major versions.
- One-click old/new role swapping, URL import, result caching, and custom-priority UI.

The authoritative v0.6 feature disposition is the 86-row
[`docs/REQUIREMENTS_TRACEABILITY_MATRIX.zh-CN.md`](docs/REQUIREMENTS_TRACEABILITY_MATRIX.zh-CN.md).
Hosted runs and publication channels are release-stage evidence, not local implementation claims.
